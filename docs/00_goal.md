# 00. ゴール・成功指標・非目標

## 誰の何を解決するか

**主対象**：日本旅行を計画中の海外アニメファン（英語で情報を取る層）。
香港・台湾・シンガポール・韓国・インドネシア・フィリピン・欧米。

**その人が今やっていること**：
1. 英語のブログ記事を5本開く → 同じ有名20箇所しか出てこない
2. 作品名でGoogle画像検索 → 場所名が分からない
3. 日本語の舞台探訪ブログに辿り着く → 機械翻訳で読む → 住所が読めない
4. Googleマップに手で1件ずつピンを立てる → 日程が組めない
5. 現地に着いて、店が閉業していたことを知る

**解決すること**：2〜5 を丸ごと消す。作品を選んだら、行ける場所が地図とルートで出る。

## 成功指標

### Phase 0 ゲート（この3つで続行/撤退を決める）

| 指標 | 目標 | 測り方 |
|---|---|---|
| 到達 | コミュニティ投稿3本で累計クリック **300** | Cloudflare Analytics |
| 意図 | 「Export route」ボタンのクリック率 **5%** | イベント計測（未実装機能でよい。押されたらメール登録に誘導） |
| 支払い意思の前段 | メール登録 **30件** | Substack / Buttondown |

**3つのうち2つ未達なら Phase 1 に進まない。**
言葉ではなく行動で測る。「便利そう」というコメントは指標に数えない。

### Phase 1 以降（参考値）

| 時期 | 指標 |
|---|---|
| 6ヶ月 | 月間セッション 10,000 / 収録ロケーション 2,000 / メール 500 |
| 12ヶ月 | 月間セッション 50,000（＝ディスプレイ広告の下限） / 有料 100人 |

金額の検算は `docs/50_monetization.md` と、別途 `realistic-monetization` スキルで行う。

## 非目標（やらないと決めたこと）

**明示的に書いておく。実装中にここへ引きずられるのが最大の失敗要因。**

| やらないこと | 理由 |
|---|---|
| アニメのスクリーンショット・キャプチャの掲載 | 権利。詳細は `40_legal.md` |
| ユーザーレビュー・写真投稿などのUGC | モデレーション責任が発生する。低責任・ストック型という前提と矛盾する |
| 予約・決済の代行、ツアー催行 | 納品責任が発生する |
| 日本語版サイト（当面） | 日本語圏には既存の舞台探訪コミュニティがあり、勝てないし外貨にならない |
| ネイティブアプリ | 保守コストに見合わない。Webで完結させる |
| 作品のあらすじ・レビュー・ランキング | MyAnimeList / AniList と正面衝突する。**場所のデータだけを持つ** |
| 私有地・個人宅の番地レベルの公開 | 迷惑行為の助長。`40_legal.md` 参照 |
| ログイン必須の機能 | 個人情報を持つとGDPR等の責任が増える。閲覧は完全に匿名で成立させる |

## 設計上の一貫した判断基準

迷ったらこれで決める。

1. **LLMが即答できる情報は持たない。** あらすじ、作品の解説、一般的な旅行アドバイスは書かない
2. **LLMが外す情報だけを正確に持つ。** 座標、徒歩分数、現在の営業状況、確度、最終検証日
3. **軸を増やす。** 絞り込みの軸が3つを下回る機能は、UIとして存在価値がない
4. **一次情報へのリンクを必ず出す。** AI検索に引用される側になるための条件であり、
   同時に「自分では断言しない」という責任回避の設計でもある
5. **責任を負う機能を足さない。** 予約、決済、投稿、助言。この4つに近づいたら止まる
