# 40. 権利と倫理の線引き【最重要・着手前に必読】

この企画は「アニメ」を扱うが、**アニメの表現物には一切触れない**設計で成立させる。
ここを踏み外すと、削除要請1通でサイトが終わる。

---

## 絶対にやらないこと

| 禁止 | 理由 |
|---|---|
| **アニメのスクリーンショット・キャプチャ・作画の掲載** | 複製権・翻案権。引用の要件を満たす自信があっても**やらない**。判断コストと係争リスクに見合わない |
| キャラクター画像・イラスト（公式・ファンアート問わず） | 同上。ファンアートは二重に危険 |
| 公式ロゴ・作品ロゴの画像使用 | 商標。テキストで作品名を書けば足りる |
| 話数・タイムコードの詳細な列挙 | 作品の実質的な再現に近づく。`scene_note` は場面の一言説明に留める |
| あらすじ・脚本の要約 | 翻案。そもそも `00_goal.md` の非目標 |
| 他サイトの説明文・レビュー文の転載や言い換え | 著作権。**事実（地名・座標・住所）のみ抽出する** |
| 音楽・主題歌の埋め込み | |

## やってよいこと

- **作品名をテキストで書く**（指名的言及。「この場所は〈作品名〉に登場した」という事実の記述）
- **実在の場所の座標・住所・アクセスを記述する**（事実にはそもそも著作権がない）
- 自分で撮影した写真の掲載
- ライセンスが明確な写真の掲載（Wikimedia Commons の CC/PD。**帰属表示を必ず出す**）
- 出典元へのリンク（リンク自体は自由）

## 免責と姿勢

- フッターに恒常表示：
  「This site is an independent fan-made reference. It is not affiliated with, endorsed by,
  or sponsored by any anime studio, publisher, or rights holder. All series titles are
  the property of their respective owners.」
- **削除要請には即応する。** 連絡先を `/contact` に明記し、要請があれば議論せず該当データを落とす。
  争わないことが最も安く済む

## スクレイピングの線引き

| 対象 | 方針 |
|---|---|
| robots.txt | **必ず読み、Disallow を守る。** 例外を作らない |
| レート | 1リクエスト2秒以上の間隔。同一ドメインへの同時接続は1 |
| User-Agent | 連絡先URLを含む固有のUAを名乗る。匿名化しない |
| 認証・有料の壁 | 越えない |
| 取得したもの | **事実のみをスキーマに落とし、原文HTML/本文を保存しない** |
| 出典 | 全レコードに出典URLを持ち、サイト上に表示する |

商用データベース（食べログ等）からの取得は行わない。この企画に必要ない。

## 迷惑行為への配慮（これは倫理であり、同時に差別化）

聖地巡礼は**地元とのトラブルが起きている領域**で、実際に立入禁止化・撤去された場所がある。
そこに情報を流し込むサイトは、いずれ地元と自治体を敵に回す。逆に、ここを丁寧にやると
**自治体が味方になる**（＝一次情報の提供元になり、被リンクをくれる）。

**設計に埋め込むルール：**

1. **個人宅・私有地は座標を出さない。** `visitability: private` のレコードは
   最寄り駅までしか表示しない。番地は持たない
2. **`etiquette_en` を必須項目に近い扱いにする。** 住宅街、参拝者のいる神社、
   通学路、営業中の店舗には注意文を必ず添える
3. **学校は原則載せない。** 生徒がいる。モデルになった校舎は「外観のみ・公道から」に限定
4. **`closed` になった場所は理由を書く。**「迷惑行為により立入禁止」なら、そう書く。
   これ自体が最も効く抑止になる
5. トップに一文置く：「Go quietly. These are real neighbourhoods.」

**この方針は、コンテンツの差別化としても効く。** 英語圏の既存記事は例外なくこの視点がない。

## 自分のデータのライセンス

- 収集した**事実データ（座標・アクセス）は CC BY-SA 4.0 で公開**する方針を推奨
  - 理由：引用・再利用されるほど帰属リンクが増える。AI検索に引用される側になる条件でもある
  - OSM由来のデータを含む場合は ODbL の継承義務を確認すること
- サイトの文章・UI・ルート生成ロジックは通常の著作権を留保

## 事業上の届出

- 日本国内から個人が運営する情報サイト。**開業届の要否は収益が出てから判断**
- 特定商取引法の表示は、**課金機能を実装する時点で必須**になる（Phase 2）。
  この段階で住所・氏名の開示が必要になるため、開始前に方法を検討しておくこと
  （プライバシー保護のため、Ko-fi等のプラットフォーム経由にすれば自前表示を回避できる場合がある）
- アフィリエイト表示（PR表記）は各ASPの規約と景表法に従い、**Phase 1 の実装時から入れる**
